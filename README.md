# The Second Anvil

**The Second Anvil** is a lightweight Minecraft Java Edition Data Pack that adds a new, cheaper crafting recipe for the anvil to save your iron resources.

## 📖 About
Vanilla anvils are incredibly expensive, costing 3 Iron Blocks and 4 Iron Ingots (31 Iron total). This data pack introduces a more efficient way to craft them, making it perfect for early-to-mid game survival worlds.

## ⚙️ Features
* **Cheaper Anvil Recipe:** You can now craft an anvil using only **1 Iron Block** and **4 Iron Ingots** (13 Iron total).
* **Recipe Book Support:** Includes an advancement to automatically unlock the recipe in your crafting book.
* **New Item Tag:** Includes the `secondanvil:crafting_materials` tag for better mod/data pack compatibility.

## 🔧 Installation
1. Download the latest `.zip` file from the Releases tab.
2. Place the `.zip` file into your world's `datapacks` folder (`saves/<world_name>/datapacks/`).
3. Type `/reload` in the game or restart the world.
4. Enjoy your cheaper anvils!

## 🎮 Compatibility
* **Minecraft Java Edition:** 1.21.1

# Der Zweite Amboss

**Der Zweite Amboss** ist ein leichtgewichtiges Minecraft Java Edition Datenpaket, das ein neues, günstigeres Rezept für den Amboss hinzufügt, um deine Eisenressourcen zu schonen.

## 📖 Über das Paket
Vanilla-Ambosse sind extrem teuer und kosten 3 Eisenblöcke und 4 Eisenbarren (insgesamt 31 Eisen). Dieses Datenpaket bietet eine effizientere Möglichkeit, sie herzustellen – perfekt für Survival-Welten im Früh- bis Mittelspiel.

## ⚙️ Funktionen
* **Günstigeres Amboss-Rezept:** Du kannst einen Amboss jetzt mit nur **1 Eisenblock** und **4 Eisenbarren** herstellen (insgesamt 13 Eisen).
* **Rezeptbuch-Support:** Enthält ein Advancement, das das Rezept automatisch im Crafting-Buch freischaltet.
* **Neuer Item-Tag:** Enthält den Tag `secondanvil:crafting_materials` für eine bessere Kompatibilität mit anderen Mods und Datenpaketen.

## 🔧 Installation
1. Lade die neueste `.zip`-Datei aus dem Releases-Tab herunter.
2. Lege die `.zip`-Datei in den `datapacks`-Ordner deiner Welt (`saves/<Weltname>/datapacks/`).
3. Gib im Spiel `/reload` ein oder starte die Welt neu.
4. Viel Spaß mit deinen günstigeren Ambossen!

## 🎮 Kompatibilität
* **Minecraft Java Edition:** 1.21.1
